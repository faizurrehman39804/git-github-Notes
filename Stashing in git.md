# Stashing in Git:-
-> changes ko koch wawahte ka lia hathna {ghsa ka ager ek problem ayy ka mogha sabe ko hatha na h aorr kissi per moha commit ker ka esss ko dobara stashing sa nikal do}

1: `git stash` -> ess sa file site per cahla ghy gha orr per onn per commit nahi hogha orr ghalthi sa bi nahi ho sakhtha. 

2: `git stash pop` -> [stach file ko stash sa baher nikalna].

3: `git stash list` [stach file ko dikhana ka oss ma stach ma file tho nahi para].
